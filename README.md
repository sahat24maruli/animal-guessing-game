# Animal Adventure MVP
Self-contained HTML5 game for GitHub Pages.

## Improvements
- Animal-like sound for all 10 animals.
- Cow has a clearer custom cartoon SVG illustration and a longer low "moo"-like sound.
- English pronunciation with browser Text-to-Speech.
- Mobile-friendly UI.
- No image/audio assets or paid services required.

## GitHub Pages
Upload `index.html`, the `css` folder and the `js` folder to the repository root.
Then: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Note: browsers require a user interaction before audio can play, so the game starts with a Start Game button.
